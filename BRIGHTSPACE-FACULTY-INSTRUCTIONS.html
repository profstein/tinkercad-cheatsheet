Brightspace Setup Instructions

Use this guide to upload the cheat-sheet images into your Brightspace course files, replace `_img-folder-path_`, and paste the Brightspace HTML into a content page.

Best Starting Point

Use the Brightspace HTML file with inline CSS, not the regular public web page.

This page mirrors the Markdown instructions, but is easier to link on the public web.

What You Need

Gather the HTML file, the images, and your Brightspace course

  • The Brightspace HTML file you want to use
  • The images from `assets/images`
  • Access to `Tools > Course Admin > Manage Files` in Brightspace

Setup Steps

How to prepare the Brightspace version

  1. Download the images in `assets > images`.
  2. Log in to your Brightspace course.
  3. Go to `Tools > Course Admin`.
  4. Click `Manage Files`.
  5. Create a new folder, or use an existing folder structure you already have.
  6. Click `Upload`.
  7. Copy the path shown in the Upload dialog box under `Destination Folder`.
  8. Upload all of the images from step 1 and click `Save`.
  9. Open `tinkercad-cheat-sheet-brightspace.html`.
  10. Do a find and replace on `_img-folder-path_`.
  11. Replace it with the full Brightspace folder path from step 7.
  12. Keep the trailing slash at the end of the folder path.
  13. Copy the HTML from the file.
  14. In Brightspace, open the page, module, or content item where you want to place the cheat sheet.
  15. Switch to the HTML source editor.
  16. If needed, click the three dots `...` and then click the `</>` icon.
  17. Paste the HTML.
  18. Click `Update` to save changes.

Example Replacement

Replace the image path placeholder

Make sure you copy the trailing slash at the end of the Brightspace folder path.

_img-folder-path_imagename.png

Replace it with something like:

/content/enforced/COURSE-ID/3d/cheatsheet images/imagename.png

Notes

Things to watch for

  • Each course has a different Brightspace course ID.
  • The image-folder portion needs to change for each section.
  • Use the Brightspace version of the HTML, not the public web version.
  • The Brightspace HTML uses inline CSS because Brightspace may strip embedded styles.
