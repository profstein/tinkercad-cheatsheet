Key Reminder

Build rough, then refine

Start with big simple forms. Get the idea working first, then clean up, center, duplicate, and sharpen the details.

Core Idea

Everything starts with simple shapes

  • Add with solid shapes.
  • Subtract with holes.
  • Combine parts by grouping.

Shapes

Box, Cylinder, Sphere

  • Resize using corner and side handles.
  • Stretch in different directions.
  • Combine shapes to build more complex objects.

Holes

Turn shapes into cutting tools

  1. Place a hole inside a solid.
  2. Select both shapes.
  3. Click Group.

Result: the solid is cut.

  • The shapes must overlap for the cut to work.
  • No overlap means no cut.

Grouping

Make one object from many parts

Union
Bundle
Ungroup

Grouping combines shapes into a single object.

  • Union: combines shapes into one solid.
  • Bundle Group: keeps selected objects together while preserving the individual parts inside the bundle.
  • Intersect: keeps only the overlap.

Ungroup

  • Use Ungroup to undo a group.
  • Helpful for fixing mistakes or adjusting parts.

Align

Make placement precise

Align
  • Select multiple shapes.
  • Click Align.
  • Choose the alignment points you want.

Use It For

  • Centering objects
  • Creating symmetry

Duplicate

Repeat shapes quickly

Duplicate and Repeat
  • Cmd/Ctrl + D does the same thing as the Duplicate and Repeat button.
  • Use the Duplicate and Repeat button when you want the next copy to repeat the same spacing or movement.
  • Option/Alt + drag duplicates without repeat.

Use It For

  • Repeating elements
  • Symmetry
  • Even spacing

Scale

Resize with intention

  • Drag corner handles to resize.
  • Adjust width, height, and depth.
  • Option/Alt scales from the center.

Move Object

Shift position carefully

  • Left click and drag to move an object.
  • Use the arrow keys on the keyboard for more control.

Navigate

Control the camera

  • Right click + drag: rotate view
  • Scroll wheel: zoom
  • Shift + right click + drag: pan

Additional Tools

  • Use the view cube to snap to a face.
  • Use the Home button to return to the default view.

Workflow

How to build

  1. Block it out: use simple shapes first and do not worry about precision yet.
  2. Adjust proportions: scale the form to match your idea.
  3. Add details: use holes and grouping.
  4. Clean up: align, center, and duplicate for symmetry.
  5. Check your work: rotate and inspect from all angles.

Common Mistakes

What trips beginners up

  • Hole not cutting because shapes are not overlapping
  • Grouping too early
  • Objects slightly off-center
  • Trying to be precise too early

Strong Models

What good work usually has

  • Clean cuts
  • Centered and aligned parts
  • Consistent proportions
  • Built from multiple shapes
