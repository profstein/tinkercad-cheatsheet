# Tinkercad Cheatsheet

A small public teaching kit for Tinkercad, designed for use in introductory multimedia courses but
available to anyone teaching or learning beginner 3D modeling.

## What This Includes

- `tinkercad-cheat-sheet.html`
  The main public web cheat sheet
- `tinkercad-cheat-sheet-brightspace.html`
  A reusable Brightspace version with `_img-folder-path_` placeholders
- `tinkercad-cheat-sheet-brightspace-1101.html`
  A section-specific Brightspace copy
- `BRIGHTSPACE-FACULTY-INSTRUCTIONS.md`
  Faculty instructions for uploading images and preparing the Brightspace HTML
- `BRIGHTSPACE-FACULTY-INSTRUCTIONS.html`
  HTML version of the same Brightspace instructions
- `assets/images`
  The images used by the cheat sheet and Brightspace versions

## Who It Is For

- Instructors teaching introductory multimedia or digital design
- Students learning the basics of Tinkercad
- Faculty who want a quick reference they can post on the open web or paste into Brightspace

## Public Web Version

The main student-facing page is:

- [tinkercad-cheat-sheet.html](./tinkercad-cheat-sheet.html)

If this repository is published with GitHub Pages, `index.html` serves as the landing page and
links to the main cheat sheet and Brightspace support materials.

## Brightspace Use

If you want to use this in Brightspace, start here:

- [BRIGHTSPACE-FACULTY-INSTRUCTIONS.html](./BRIGHTSPACE-FACULTY-INSTRUCTIONS.html)
- [BRIGHTSPACE-FACULTY-INSTRUCTIONS.md](./BRIGHTSPACE-FACULTY-INSTRUCTIONS.md)

The Brightspace workflow is:

1. Download the images from `assets/images`
2. Upload them into your Brightspace course files
3. Copy the Brightspace destination folder path
4. Replace `_img-folder-path_` in the Brightspace HTML file
5. Paste the resulting HTML into a Brightspace content page
